# 性能测试规划

验证 Agent 延迟和端到端耗时，而不是只测单次函数速度。

必须覆盖：

- 节点、LLM、MCP、等待和持久化耗时可重算。
- 双器件 critical path 和阶段 deadline 正确。
- 只读并行不会跨会话或模型卡版本。
- 副作用操作保持串行，缓存正确失效且缓存命中不计 MCP 调用。
- 优化前固定 manifest、fixture/seed、版本、分位数算法、最小改善量和质量非劣阈值，执行配对 A/B；`n<20` 报告全部样本和 max，`n≥20` 才报告 P50/P95。
- 同时比较严格包率、有效交付率、QA、最差器件和恢复指标；不以“可解释”为由接受越过非劣阈值的退化。
- 近正式演练逐次验收：第 6 小时前形成双基线、第 22 小时前冻结模型卡、第 23 小时前形成有效包、官方 24 小时截止前平台确认；少量演练不计算 P95。

未实现代码前，本目录仅保存测试规范，不代表性能目标已经达成。
