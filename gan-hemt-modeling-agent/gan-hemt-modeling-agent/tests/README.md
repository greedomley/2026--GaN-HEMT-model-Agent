# `tests` 说明

测试按单元、契约、集成、端到端、性能、故障恢复、完成判定、失败控制、回归和竞赛演练分层。

测试目标不仅是程序可运行，还要验证模型卡有效、物理 QA、双器件鲁棒性、调用审计和断点恢复。

四项 Agent 能力的专项测试规划：

- [性能](performance/README.md)：关键路径、原始值/max、具备样本条件时的 P50/P95、deadline、安全并行和缓存失效。
- [恢复](recovery/README.md)：未知远端结果对账、检查点回退、恢复单一所有权和零重复副作用。
- [完成率](completion/README.md)：单/双器件包结果、截止前平台交付和失败安全的分离。
- [失败控制](failure_control/README.md)：逐阶段失败分类、有限自愈、熔断与回归闭环。

专项目录目前保存测试规范；只有测试代码和报告真实存在时才能标记对应能力已通过。
