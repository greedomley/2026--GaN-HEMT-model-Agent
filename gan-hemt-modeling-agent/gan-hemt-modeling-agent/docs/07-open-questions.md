# 待官方材料确认事项

以下事项直接影响实现，不应在获得赛题 Q&A 或官方说明前自行假定。

## MCP 与 MeQLab

- Modeling MCP Server 的完整工具清单和参数定义是什么？
- 数据 I/O 是返回数据本身、摘要、图像，还是仅返回服务端引用？
- 会话有效期、断线恢复和模型卡检查点能力是什么？
- 拟合目标函数、优化器、参数冻结和约束能力有哪些？
- QA Checklist 能否由 MCP 完整执行并返回逐项结果？
- 单 Token 是否允许两器件并发？是否存在 QPS、并发和总调用限制？
- 无意义调用的审计判定标准是什么？

## 模型与参数

- ASM-HEMT 的具体版本是什么？
- 官方模型卡 Schema、必填字段、单位和命名规则是什么？
- 约 120 个参数中，哪些开放提取、哪些固定、哪些有官方范围？
- 模型初始化由官方模板、MeQLab 默认值还是参赛方提供？
- 场板、自热、陷阱等效应是否对所有器件启用？

## 输入与评分

- DC I-V、C-V、Pulse I-V、S 参数的偏置、温度和频率覆盖如何表达？
- 归一化 RMSE 的归一化方式、曲线权重和不同数据类型权重是什么？
- 隐藏网格是否只包含 `(Vgs, Vds, T)`，还是也考察频率/脉冲条件？
- QA 各项是否等权？失败等级是否不同？
- 允许提交前通过 MCP 自行复现多少验证点？

## LLM 与运行环境

- 国产大模型的指定范围、版本和代理服务是否有限制？
- 是否允许主备模型、不同节点使用不同模型、结构化输出和本地缓存？
- LLM 调用统计需要哪些字段，是否要求提供完整提示词？
- 组委会统一环境是否限制容器、数据库、网络出口或文件大小？

## 提交与开源

- 测试日前代码仓库的提交平台、截止时间和更新规则是什么？
- 模型卡、日志和总结的官方命名、压缩和上传方式是什么？
- 日志中哪些内容必须脱敏，哪些内容必须完整保留？
- 获奖后开源范围是否包含配置、提示词、测试脚本和合成数据生成逻辑？
